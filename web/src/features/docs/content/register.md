注册 {{SITE_NAME}} 账户需要用户名、密码和一个能收到验证码的邮箱。本页按点击顺序介绍注册、登录、找回密码，以及如何在控制台中加固账户安全。

## 注册账户

1. 打开 [注册页](/sign-up)，页面标题为「创建一个账户」。已有账户时点击「登录」切换到登录页。
2. 填写「用户名」「密码」「确认密码」。密码需要 8–128 个字符。
3. 在「电子邮件（验证必需）」中填写常用邮箱，点击「发送验证码」，再把邮件中的验证码填入「验证码」输入框。按钮会进入 30 秒倒计时，结束后才能重新发送。
4. 页面出现人机验证组件时，按提示完成验证。
5. 页面显示「我已阅读并同意」以及「用户协议」「隐私政策」链接时，需要先勾选，按钮才能点击。
6. 点击「创建账户」。提示「账户已创建！请登录」后，页面会自动跳转到登录页。

> [!NOTE]
> 点击「发送验证码」后人机验证会重置。如果最后「创建账户」按钮无法点击，请重新完成一次人机验证。

### 使用第三方账户

如果站点开启了第三方登录，注册页底部会出现「或继续使用」区域和对应按钮，例如「使用 GitHub 继续」。点击后按提示授权，即可直接创建并登录账户。具体有哪些方式以页面显示为准。

通过第三方方式注册的账户默认没有登录密码，之后可以在「安全与访问」中点击「设置密码」补上，见本页「账户安全设置」一节。

### 通过邀请链接注册

收到形如 `{{BASE_URL}}/sign-up?aff=邀请码` 的邀请链接时，直接打开它完成注册即可，邀请码会自动带上。邀请奖励在钱包页的「推荐计划」中查看，见 [计费说明](/docs/billing)。

## 登录

1. 打开 [登录页](/sign-in)。
2. 在「用户名或电子邮件」中填写用户名或注册邮箱，在「密码」中填写密码。
3. 页面出现人机验证组件或协议勾选框时，先完成验证并勾选。
4. 点击「登录」，成功后进入控制台。

登录页还可能提供以下方式，以页面实际显示为准：

| 方式       | 入口                     | 说明                                                                 |
| ---------- | ------------------------ | -------------------------------------------------------------------- |
| Passkey    | 「使用 Passkey 登录」    | 先在「安全与访问」中启用 Passkey，之后可以用指纹、面容或安全密钥登录 |
| 第三方账户 | 「或继续使用」下方的按钮 | 例如「使用 GitHub 继续」「使用 Telegram 继续」                       |

### 完成两步验证

账户开启了两步验证时，输入密码后会进入「安全验证」页面，提示「请验证身份以完成登录。」。填写验证器应用中的 6 位验证码，或一个未使用过的备用代码，然后点击「验证」。

如果页面提示会话已过期，点击「会话已过期？」后面的「重新登录」，回到登录页重新开始即可。

## 找回密码

找回密码依赖账户绑定的邮箱。没有绑定邮箱的账户（例如只用第三方方式注册的账户）请继续使用原来的方式登录。

1. 在 [登录页](/sign-in) 点击「忘记密码？」，进入「忘记密码」页面。
2. 在 Email 输入框中填写注册邮箱。
3. 完成人机验证（如有），点击「发送重置邮件」。看到「重置邮件已发送，请检查您的收件箱」后，30 秒内不能再次发送。
4. 打开邮件中的链接，进入「重置密码」页面，核对邮箱后点击「确认重置密码」。
5. 页面会显示系统生成的「新密码」，并自动复制到剪贴板。
6. 点击「返回登录」，用新密码登录。

> [!IMPORTANT]
> 新密码由系统随机生成，无法自行指定。登录后请尽快在「安全与访问」中点击「更改密码」，换成自己的密码。

如果重置页面提示「无效的重置链接，请请求新的密码重置。」，或者确认时报错，请回到登录页重新申请一封重置邮件。

## 账户安全设置

登录后，在左侧菜单「个人」分组中点击「安全与访问」。页面分为以下几个区域：

| 区域       | 用途                                                      | 操作入口                                                                                 |
| ---------- | --------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 登录与认证 | 修改登录密码；绑定邮箱、微信、GitHub、Telegram 等登录方式 | 「更改密码」（账户没有密码时显示「设置密码」）；「账户绑定」中的「绑定」「更改」「解绑」 |
| 会话与访问 | 查看正在使用账户的设备；管理访问令牌                      | 「登录会话」中的「退出其他会话」；「访问令牌」中的「创建访问令牌」                       |
| 账户操作   | 永久删除账户                                              | 「删除账户」                                                                             |
| 安全验证   | Passkey 和两步验证                                        | 「Passkey 登录」卡片中的「启用 Passkey」；「两步验证」卡片中的「启用」                   |
| 隐私       | 是否在使用日志和错误日志中记录 IP                         | 「记录 IP 地址」，修改后点击「保存设置」                                                 |

「账户绑定」中可以绑定哪些方式，以页面实际显示为准。

> [!NOTE]
> 设置密码、绑定账户、启用 Passkey 等敏感操作前，可能会弹出「安全验证」对话框，需要先用密码、验证器验证码或 Passkey 确认身份。

### 修改密码

1. 在「登录与认证」中点击「更改密码」。
2. 填写「当前密码」「新密码」「确认新密码」，新密码需要 8–128 个字符，然后提交。

通过第三方方式注册、还没有密码的账户，这里显示为「设置密码」，完成身份验证后即可设置。

### 开启两步验证

1. 在「安全验证」区域的「两步验证」卡片中点击「启用」，弹出「设置双重身份验证」对话框。
2. 「扫描二维码」：用 Google Authenticator、Microsoft Authenticator 等验证器应用扫描二维码，也可以手动输入页面上的密钥。点击「下一步」。
3. 「保存备份代码」：点击「复制所有代码」，把备份代码存放在安全的地方。每个备份代码只能使用一次。点击「下一步」。
4. 「验证设置」：输入验证器应用中的 6 位验证码，点击「启用 2FA」。

开启后，卡片会显示剩余备份代码的数量。备份代码快用完时点击「重新生成备用代码」，不再需要两步验证时点击「禁用 2FA」。

> [!WARNING]
> 手机丢失且备份代码也用完时将无法完成登录验证。请把备份代码离线保存，不要只存在同一部手机上。

### 启用 Passkey

在「Passkey 登录」卡片中点击「启用 Passkey」，按浏览器提示用指纹、面容或安全密钥完成注册。之后就可以在登录页点击「使用 Passkey 登录」。如果卡片提示「此设备不支持通行密钥」，请换用支持生物识别或安全密钥的浏览器和设备。

### 访问令牌与 API 密钥的区别

「会话与访问」中的「访问令牌」用于在脚本中调用控制台的管理接口，每个访问令牌只拥有创建时勾选的权限，不能用来调用模型。调用模型要使用「API 密钥」页面创建的 API 密钥，见 [创建 API 密钥](/docs/api-keys)。

> [!CAUTION]
> 「删除账户」会永久删除账户和所有数据，操作无法撤消。删除前请确认账户余额和令牌都已不再需要。

## 常见问题

### 收不到邮箱验证码

先查看垃圾邮件文件夹，并确认邮箱地址没有填错。按钮倒计时结束后，可以再次点击「发送验证码」。

### 「创建账户」按钮无法点击

页面显示协议勾选框时，需要先勾选。另外请确认人机验证已经完成，发送验证码后人机验证会重置，需要重新完成一次。

### 在哪里查看登录记录

左侧菜单「常规」中的「审计日志」记录了登录、安全设置变更等操作。
