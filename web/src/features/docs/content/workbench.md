AI 工作台（OnlyArt）是 {{SITE_NAME}} 提供的网页版创作工具，地址为 {{WORKBENCH_URL}}。它使用 {{SITE_NAME}} 账户登录，在你的账户下自动创建令牌来调用模型，费用从 {{SITE_NAME}} 余额扣除。各项功能的用法见 [工作台功能](/docs/workbench-features)。

## 工作台与 {{SITE_NAME}} 的关系

| 项目 | 说明                                                                                                                     |
| ---- | ------------------------------------------------------------------------------------------------------------------------ |
| 账户 | 只能使用 {{SITE_NAME}} 账户登录，无需单独注册；首次登录时自动创建对应的工作台账户                                        |
| 密钥 | 工作台按用途在你的 {{SITE_NAME}} 账户下创建令牌，默认命名为 `onlyart-<显示名>-<分组>`，可以在 [API 密钥](/keys) 页面看到 |
| 模型 | 接入令牌后自动同步该令牌所属分组的模型，上游新增或下线模型时跟随更新                                                     |
| 计费 | 调用通过该令牌发往 {{SITE_NAME}}，按模型价格 × 分组倍率从余额扣费，规则见 [计费说明](/docs/billing)                      |

> [!NOTE]
> 通过你接入的 {{SITE_NAME}} 密钥调用模型时，工作台不另外收费。工作台头像菜单中显示的「余额」就是你的 {{SITE_NAME}} 账户余额。

## 登录

1. 打开 [AI 工作台]({{WORKBENCH_URL}})，点击「登录」，或直接访问 `{{WORKBENCH_URL}}/login`。
2. 在登录页点击「使用{{SITE_NAME}}账号进行登录」。
3. 如果浏览器中还没有登录 {{SITE_NAME}}，会先跳转到 {{SITE_NAME}} 的 [登录页](/sign-in)。还没有账户时，请先 [注册](/docs/register)。
4. 登录成功后自动返回工作台，默认进入「新对话」页面。第一次登录会先弹出引导。

未登录时也能浏览部分页面，但侧边栏底部会提示「登录后可保存对话、创建图片并上传文件。」登录页顶部可以切换界面语言：简中、繁中、EN、日本語、한국어。

| 登录页提示                           | 含义                                  | 处理方法                     |
| ------------------------------------ | ------------------------------------- | ---------------------------- |
| 「登录暂未开放」                     | 管理员尚未完成 {{SITE_NAME}} 登录配置 | 稍后再试，或联系管理员       |
| 「暂时无法连接服务」                 | 工作台服务暂时不可用                  | 点击「重新加载」             |
| 「{{SITE_NAME}} 登录失败，请重试。」 | 授权过程中断或已超时                  | 回到登录页，重新点击登录按钮 |

## 首次登录引导

第一次登录工作台时会弹出四步引导，帮你按用途选好 {{SITE_NAME}} 分组并创建密钥。

1. 「选择你的使用偏好」：选择「新手上路」进入下一步；选择「我有经验」会跳过分组配置，直接进入第 4 步。
2. 「选择你想使用的能力」：在「对话交互」「图片创作」「视频创作」中多选，至少保留一项，然后点击「下一步」。
3. 「配置模型分组密钥」：工作台列出与所选能力匹配、且管理员已开放的 {{SITE_NAME}} 分组，每项显示分组名、「倍率: Nx」和部分模型。每类用途会预选倍率较低的分组，你可以增减勾选，也可以修改「密钥名称」。对话用途建议勾选支持 openai 端点的分组，原因见下文。点击「创建所选密钥 (N)」，分组显示「已接入」即创建成功；显示「失败」时可以查看原因并点击「重试」。
4. 「准备就绪，开启创作」：点击「智能对话」「图片创作」「视频生成」「创意画布」等入口直接开始，或点击「进入工作台」。

> [!TIP]
> 第 3 步可以点击「稍后配置」跳过。跳过或选择「我有经验」时不会创建密钥，之后可以随时在「API 与模型」中接入。引导完成后不再显示。

引导创建的密钥就是你 {{SITE_NAME}} 账户中的令牌，默认名称为 `onlyart-<显示名>-<分组名>`，永不过期、不限额度，实际花费受账户余额约束。

## 在「API 与模型」中接入分组

接入、更换或新增分组都在设置中完成：点击侧边栏底部的头像，选择「设置」，再切换到「API 与模型」。也可以直接打开 [API 与模型]({{WORKBENCH_URL}}/chat?settings=api)。

### 按用途一键接入

页面按用途分为三张卡片：「对话」（问答、推理与代码模型）、「生图」（图片生成与编辑模型）、「视频」（视频生成与处理模型）。

1. 在卡片的「{{SITE_NAME}} 分组」下拉框中选择分组。每个选项显示为「分组名 · N 个模型 · x倍率」。
2. 点击「一键创建并导入」。工作台会在你的 {{SITE_NAME}} 账户下创建该分组的令牌，并导入分组内的全部可用模型。
3. 成功后提示「已接入 分组名，同步 N 个模型」，新密钥出现在下方「已接入密钥」列表中。

工作台根据模型名判断分组适合哪类用途，因此同一个分组可能同时出现在多张卡片中。下拉框显示「管理员暂未开放此类分组」时，说明当前没有可接入的此类分组。

| 用途 | 可参考的分组                                                          |
| ---- | --------------------------------------------------------------------- |
| 对话 | `codex-*`、`DeepSeek`、`glm`、`kimi`、`qwen` 等支持 openai 端点的分组 |
| 生图 | `生图`                                                                |
| 视频 | `满血视频`、`特价视频`                                                |

实际可选的分组以下拉框为准，各分组的倍率和模型见 [分组说明](/docs/groups)。

> [!IMPORTANT]
> 工作台以 OpenAI 兼容的 Chat Completions 格式调用对话模型。只标注了 anthropic 或 gemini 端点的分组（如 `claude-*`、`gemini`）即使出现在「对话」卡片中，也不保证能在工作台对话中正常使用。

> [!NOTE]
> 一键接入的密钥使用默认名称 `onlyart-<显示名>-<分组名>`。对已用默认名称接入的分组再次点击「一键创建并导入」时，不会重复创建令牌，只会重新导入该分组的模型。

### 手动填写密钥

如果你已经在 {{SITE_NAME}} 的 [API 密钥](/keys) 页面创建了令牌（例如想限制额度或模型），可以点击「手动填写密钥」，在「添加 API 密钥」对话框中填写：

- 「API 密钥」：粘贴以 `sk-` 开头的密钥，例如 `sk-xxxxxxxx`。密钥会加密保存在服务器，页面只显示末尾四位。
- 「优先级」「权重」：有多个密钥时的调用顺序和比例，一般保持默认即可。
- 「启用」「设为默认密钥」「保存后自动识别并导入全部可用模型」：按需勾选。

点击「保存」。新建时默认勾选「保存后自动识别并导入全部可用模型」，保存后会导入该密钥可用的模型。这里只能填写 {{SITE_NAME}} 的密钥，接口地址由工作台自动设置，无需填写。

> [!NOTE]
> 如果接入时提示「当前账号不允许使用个人 API 密钥」或「当前用户分组或套餐不允许使用个人 API 密钥」，说明管理员限制了你的账户接入密钥，请联系管理员。

### 管理已接入的密钥

「已接入密钥」列表中，每个密钥显示「{{SITE_NAME}} · 分组 · 末四位 · N 次调用」和连接状态（「连接正常」「连接异常」「待检测」或「已停用」）。

| 操作                 | 作用                                                     |
| -------------------- | -------------------------------------------------------- |
| 「自动同步上游模型」 | 勾选后自动跟随分组更新模型列表，旁边显示「上次同步」时间 |
| 「立即同步模型」     | 马上重新读取模型，完成后提示新增和下线的数量             |
| 「编辑」             | 更换密钥，或调整优先级、权重、启用状态                   |
| 「删除」             | 从工作台移除该密钥，以及只依赖它的模型                   |

> [!WARNING]
> 在工作台中「删除」密钥，不会删除 {{SITE_NAME}} 账户里的令牌。不再使用时，请到 [API 密钥](/keys) 页面禁用或删除它。反过来，如果在 {{SITE_NAME}} 中删除或禁用了工作台创建的令牌，工作台中的调用会失败，处理方法见下方的常见问题。

## 查看费用与用量

通过接入的 {{SITE_NAME}} 令牌发起的调用，用量和扣费都记录在 {{SITE_NAME}} 控制台中。

| 想查看的内容     | 位置                                                            |
| ---------------- | --------------------------------------------------------------- |
| 当前余额         | 工作台头像菜单中的「余额」，或 {{SITE_NAME}} 的 [钱包](/wallet) |
| 工作台创建的令牌 | [API 密钥](/keys) 页面，默认名称以 `onlyart-` 开头              |
| 每次调用的费用   | [使用日志](/usage-logs)，用「令牌名称」筛选工作台使用的令牌     |
| 视频等异步任务   | 控制台侧边栏的「任务日志」                                      |
| 充值             | [钱包](/wallet)，见 [计费说明](/docs/billing)                   |

> [!TIP]
> 各模型的单价和分组倍率以 [模型广场](/pricing) 为准。生图通常按次计费，视频按输出秒数或按任务计费，对话按 tokens 计费。

## 常见问题

### 第 3 步或「API 与模型」中看不到分组

- 引导提示「暂无与所选能力匹配的开放分组，你可以稍后在设置中接入。」，或下拉框显示「管理员暂未开放此类分组」：通常是管理员还没有开放这类分组，请联系管理员，或先使用其他用途。
- 分组读取失败时，下拉框也会显示「管理员暂未开放此类分组」。可以关闭设置后重新打开「API 与模型」再试；引导中出现报错时，点击「重试加载」。

### 接入时提示错误

| 提示                                | 原因与处理                                                                          |
| ----------------------------------- | ----------------------------------------------------------------------------------- |
| 「该分组暂未开放」                  | 该分组未对工作台开放，请换一个分组                                                  |
| 「Key 名称已存在，请换一个名称」    | 引导中填写的密钥名称已被其他分组使用，请修改「密钥名称」后重试                      |
| 「当前账号未绑定 {{SITE_NAME}}」    | 当前账户不是通过 {{SITE_NAME}} 登录的，请退出后重新登录                             |
| 「{{SITE_NAME}} 分组 Key 创建失败」 | 创建令牌失败，可能是令牌数量已达上限；可以在 [API 密钥](/keys) 删除不用的令牌后重试 |

### 余额不足

{{SITE_NAME}} 余额不足时，工作台中的生成会失败。工作台可能不会直接提示余额不足，失败原因有时显示为「……请求较多，请稍后重试。」。连续失败时，先查看头像菜单中的「余额」或 {{SITE_NAME}} 的 [钱包](/wallet)，充值后再到「任务中心」重试失败的任务。

### 令牌被删除或禁用

如果在 {{SITE_NAME}} 中删除、禁用了工作台使用的令牌，或改小了它的额度和过期时间，工作台中的生成会失败，同步模型时该密钥会显示「连接异常」。

- 令牌被禁用或修改过：在 [API 密钥](/keys) 页面重新启用，或恢复「无限配额」和「永不过期」，再回到「API 与模型」点击「立即同步模型」。重新接入同一分组会复用这个令牌，不能解决问题。
- 令牌已被删除：在「API 与模型」中删除这个密钥，再对同一分组点击「一键创建并导入」，工作台会重新创建令牌。

### 选不到模型，或提示模型在当前分组不可用

- 模型选择器显示「暂无配置密钥」时，说明还没有接入任何密钥，点击「点击进行配置」即可进入「API 与模型」。
- 某个用途没有可选模型，说明还没有接入该用途的分组，例如生图需要接入 `生图` 分组。
- 生成多次失败、重试也无效时，可能是该模型已下线或该分组线路暂不可用。可以点击「立即同步模型」刷新列表，或稍后重试，也可以改用其他分组。

> [!TIP]
> 反馈问题时，可以在设置的「帮助与客服」中提交工单，并附上 {{SITE_NAME}} [使用日志](/usage-logs) 中的请求 ID，便于排查。更多问题见 [常见问题](/docs/faq)。
