调用接口时，在请求的 `model` 字段（Gemini 原生接口则在 URL 路径中）填写模型名。模型名必须与 {{SITE_NAME}} 展示的名称完全一致，并且属于令牌所选的分组。

## 查看可用模型

| 方式                     | 说明                                                   |
| ------------------------ | ------------------------------------------------------ |
| [模型广场](/pricing)     | 查看全部模型的价格、所属分组、计费方式和支持的端点类型 |
| [分组说明](/docs/groups) | 实时分组列表，显示每个分组包含的模型                   |
| `GET /v1/models`         | 返回当前令牌可用的模型列表（OpenAI 格式）              |

用令牌查询可用模型：

<!-- code-group -->

```bash
curl {{BASE_URL}}/v1/models \
  -H "Authorization: Bearer sk-xxxxxxxx"
```

```powershell
curl.exe {{BASE_URL}}/v1/models `
  -H "Authorization: Bearer sk-xxxxxxxx"
```

<!-- /code-group -->

返回结果中 `data` 数组的每一项代表一个模型，其中的 `id` 就是调用时要填写的模型名。返回的列表只包含该令牌所属分组可用的模型。Gemini 客户端可以通过 `GET /v1beta/models` 获取 Gemini 格式的模型列表。

## 使用模型广场

[模型广场](/pricing) 展示所有模型的价格、所属分组和支持的接口格式，是选择模型和核对价格的主要入口。

### 筛选与排序

| 位置                 | 选项                                                        | 用途                                                                     |
| -------------------- | ----------------------------------------------------------- | ------------------------------------------------------------------------ |
| 左侧「筛选」         | 供应商、「分组」「定价类型」「端点类型」「模型标签」        | 例如在「分组」中选择令牌所属的分组，只看可用的模型；点击「重置」清除筛选 |
| 「定价类型」         | 所有模型、按量计费、按次计费、按秒、任务计费                | 区分按 tokens、按次、按秒和按任务计费的模型                              |
| 「端点类型」         | Chat、Response、Anthropic、Gemini、Rerank、图片、嵌入、视频 | 按接口格式筛选，例如 Claude Code 需要 Anthropic                          |
| 顶部「价格显示模式」 | 标准、充值                                                  | 「标准」按额度（美元）显示，「充值」按实际充值金额折算显示               |
| 顶部「Token 单位」   | 1M、1K                                                      | 按量计费的价格按每 1M 或每 1K tokens 显示                                |
| 顶部「排序」         | 名称、价格：从低到高、价格：从高到低                        | 调整列表顺序                                                             |

### 模型详情

点击模型卡片打开「模型详情」，包含三个标签页：

| 标签页 | 内容                                                                                                                                             |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 概览   | 「上下文」「最大输出」等参数和价格；「按分组定价」列出同一模型在各分组的价格；视频、图片模型还会显示「视频素材能力」「分辨率价格」「价格示例」等 |
| 性能   | 「平均延迟」「平均首 Token 延迟」「成功率」，以及「延迟趋势（最近 24 小时）」「可用率（最近 24 小时）」                                          |
| API    | 「调用示例」提供已填好模型名的代码，示例通过 `NEW_API_KEY` 读取令牌，换成你的令牌即可运行                                                        |

> [!TIP]
> 「成功率」排除了余额不足、参数错误等业务拒绝，并包含当前尚未结束的小时。比较同一模型在不同分组的「成功率」和「可用率」，可以帮助选择更稳定的分组。

## 模型名规则

- 区分大小写，必须完全一致。例如 `MiniMax-M3` 不能写成 `minimax-m3`。
- 带 `[c]` 前缀的是独立的模型条目，例如 `[c]seedance-2.0` 与 `seedance-2.0` 的能力和价格都不同。调用时连同前缀一起填写：

```json
{
  "model": "[c]seedance-2.0"
}
```

- 不要使用上游官方的别名或旧名称，以模型广场显示的名称为准。

## 计费方式

模型广场会标注每个模型的计费方式：

| 计费方式 | 说明                     | 典型模型                              |
| -------- | ------------------------ | ------------------------------------- |
| 按量计费 | 按输入、输出 tokens 计费 | 大部分对话和编程模型                  |
| 按次计费 | 每次请求固定价格         | 生图模型、`酒馆` 分组的模型           |
| 视频计费 | 按输出秒数或按任务计费   | 视频模型，见 [视频生成](/docs/videos) |

实际费用都要再乘以分组倍率，详见 [计费说明](/docs/billing)。

## 端点类型

模型广场还会显示每个模型支持的端点类型，例如 openai、anthropic、gemini。请用对应格式的接口调用：Claude 模型用 [Anthropic Messages](/docs/anthropic-messages)，Codex 用 [Responses](/docs/responses)，Gemini CLI 用 [Gemini 原生接口](/docs/gemini-native)，大部分其他模型用 [Chat Completions](/docs/chat-completions)。分组与端点类型的完整对照见 [分组说明](/docs/groups)。

## 常见问题

### 提示模型不存在或无可用渠道

1. 检查模型名的拼写和大小写。
2. 用同一个令牌调用 `GET /v1/models`，确认模型在返回列表中。
3. 如果不在列表中，说明令牌所属分组不包含该模型，需要换用对应分组的令牌。

### 客户端里找不到某个模型

很多客户端只显示内置的模型列表。可以在客户端中手动添加模型名，或使用客户端自带的"获取模型列表"功能（通常会调用 `/v1/models`）。
