这里汇总了使用 {{SITE_NAME}} 时最常遇到的问题，按账户、计费、分组、客户端、图片视频和 AI 工作台分类。没有找到答案时，请带上请求 ID 联系管理员，方法见文末。

## 账户与充值

### 注册时收不到邮箱验证码怎么办

注册必须完成邮箱验证。点击「发送验证码」后，按钮会显示「重新发送 (Ns)」倒计时，结束前不能重复发送。收不到邮件时：

1. 检查邮箱地址是否填写正确。
2. 到垃圾邮件、广告邮件文件夹中查找。
3. 等倒计时结束后，再次点击「发送验证码」。

完整步骤见 [注册账户](/docs/register)。

### 忘记密码怎么办

在 [登录页](/sign-in) 点击「忘记密码？」，输入注册邮箱后点击「发送重置邮件」，再按邮件中的链接设置新密码。

### 余额的单位是什么，怎么充值

余额以美元显示。在 [钱包](/wallet) 页面的「添加资金」中选择金额和付款方式充值，可用的付款方式以页面显示为准；有兑换码时，在「有兑换码吗？」处输入兑换码，点击「兑换额度」。详见 [计费说明](/docs/billing)。

### 费用是怎么计算的

实际费用 = 模型基础价格 × 分组倍率。按量计费的模型按输入、输出 tokens 计费，按次计费的模型每次请求固定价格，视频模型按输出秒数或按任务计费。各模型的价格以 [模型广场](/pricing) 为准，每次调用的实际费用可以在 [使用日志](/usage-logs) 中查看。

### 请求失败会扣费吗

被网关直接拒绝的请求（令牌无效、余额不足、模型在当前分组不可用等）不会扣费。视频等异步任务失败后，预扣的费用会自动退还，使用日志中会出现「退款」类型的记录。

## 分组与令牌

### 一个令牌可以调用所有模型吗

不可以。每个令牌对应一个分组，只能调用该分组包含的模型。需要使用多个分组时，为每个分组分别创建令牌；也可以选择自动分组，让令牌按顺序尝试多个分组，见 [分组说明](/docs/groups)。

### 提示「分组 xxx 下模型 xxx 无可用渠道」怎么办

通常是模型不在令牌所属的分组，或模型名拼写有误。用同一个令牌调用 `GET {{BASE_URL}}/v1/models`，确认模型在返回列表中；不在列表中就换用对应分组的令牌。排查步骤见 [错误处理](/docs/errors)。

### 令牌泄露了怎么办

立即到 [API 密钥](/keys) 页面删除该令牌，重新创建后更新各客户端的配置。可以在 [使用日志](/usage-logs) 中按「令牌名称」筛选，检查是否有异常调用。

### codex-官key 与 codex-plus、codex-pro 有什么区别

`codex-plus`、`codex-pro` 分别来自 plus、pro 号池，倍率较低；`codex-官key` 是稳定高速分组，倍率较高。使用 `codex-官key` 时遇到缓存或降智问题，请直接反馈。

### 酒馆分组可以用来写代码吗

不可以。`酒馆` 分组按次计费，用于角色扮演等聊天场景，禁止用于 Vibe Code（AI 编程）。编程工具请使用 `claude-*` 或 `codex-*` 分组。

## 客户端与接口

### Base URL 要不要加 /v1

OpenAI 格式的客户端和 SDK（Codex、Cherry Studio、OpenAI SDK 等）填写 `{{BASE_URL}}/v1`；Anthropic 和 Gemini 格式（Claude Code、Gemini CLI、Anthropic SDK 等）直接填写 `{{BASE_URL}}`，客户端会自动拼接路径。少写 `/v1` 时，请求会被当成网页访问；多写一层 `/v1` 会返回 404 `Invalid URL`。

### Codex 提示 Selected model is at capacity. Please try a different model 怎么办

通常是 GPT 官方算力不足导致的，只能等待官方恢复，或暂时换用其他模型。配置方法和其他常见报错见 [Codex](/docs/codex)。

### Claude Code 可以用 codex 或国产模型分组吗

可以，只要分组支持 Anthropic 格式（端点类型包含 anthropic），例如 `codex-*`、`DeepSeek`、`glm`、`kimi`、`minimax`、`grok`。需要把 Claude Code 中的模型改成该分组内的模型，见 [Claude Code](/docs/claude-code)。

### 怎么快速把令牌导入编程工具

在 [API 密钥](/keys) 页面打开令牌的行操作菜单，点击「CC Switch」，在「填入 CC Switch」对话框中选择「应用」和「主模型」，点击「打开 CC Switch」即可导入。详见 [CC Switch 一键导入](/docs/cc-switch)。

## 图片与视频

### 生图有没有现成的网页工具

有。[生图站](https://image.realseek.wiki/) 已预先配置好 Base URL，只需填入绑定 `生图` 分组的令牌即可使用。也可以通过接口调用，见 [图片生成](/docs/images)；或在 [AI 工作台](/docs/workbench) 中创作。

### 满血视频和特价视频有什么区别

`满血视频` 的模型能力对齐官方，支持首尾帧、参考图、参考视频和参考音频；`特价视频` 能力不全，主打便宜，例如特价 Seedance 不支持首尾帧和参考视频。各模型的能力表见 [视频生成](/docs/videos)。

### 视频任务提交后客户端超时了怎么办

不要重新提交，重新提交会再次付费。用创建时返回的任务 `id` 调用查询接口获取结果，也可以在控制台 [使用日志](/usage-logs) 的「任务日志」中查看进度。

## AI 工作台

### AI 工作台要单独注册吗

不需要。打开 {{WORKBENCH_URL}}，点击「使用{{SITE_NAME}}账号进行登录」即可。工作台调用模型的费用从你的 {{SITE_NAME}} 余额扣除，详见 [AI 工作台](/docs/workbench)。

### 工作台创建的令牌在哪里

在 [API 密钥](/keys) 页面，默认名称以 `onlyart-` 开头。这类令牌不限额度，实际花费受账户余额约束。在工作台中删除密钥不会同时删除 {{SITE_NAME}} 中的令牌，不再使用时可以在 API 密钥页面手动删除。

## 联系与反馈

遇到无法解决的问题时，请准备好请求 ID（响应头 `X-Oneapi-Request-Id`，或错误信息末尾 `(request id: ...)` 中的值）、发生时间、模型和分组，再联系管理员。不要发送完整的 API Key。常见错误的处理方法见 [错误处理](/docs/errors)。
