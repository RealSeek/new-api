调用 {{SITE_NAME}} 的模型需要一个 API 密钥（形如 `sk-xxxxxxxx`，也常被称为令牌）。本页介绍如何在控制台创建和管理 API 密钥，以及如何快速验证它是否可用。

## 创建 API 密钥

1. 登录后，在左侧菜单点击「API 密钥」，进入 [API 密钥](/keys) 页面。
2. 点击「创建 API 密钥」，弹出创建表单。
3. 在「基本信息」中填写「名称」，并在「分组」中选择一个分组（见下文「选择分组」）。
4. 按需设置「过期时间」「额度设置」和「高级设置」，不确定时保持默认即可。
5. 点击「保存更改」。提示「成功创建了 1 个 API 密钥」后，新密钥会出现在列表中。

> [!TIP]
> 第一次使用时，名称写成用途（例如 `claude-code`、`cherry-studio`）即可，其余保持默认。之后可以随时在列表中「编辑」。

## 表单字段说明

| 区域     | 字段                          | 说明                                                       |
| -------- | ----------------------------- | ---------------------------------------------------------- |
| 基本信息 | 名称                          | 必填，只用于区分不同密钥                                   |
| 基本信息 | 分组                          | 决定这个密钥走哪个分组、能用哪些模型、按什么倍率计费       |
| 基本信息 | 过期时间                      | 可选「永不过期」「1 个月」「1 天」「1 小时」，或自定义时间 |
| 基本信息 | 数量                          | 一次创建多个相同配置的密钥，仅创建时可用                   |
| 额度设置 | 额度 (USD)                    | 这个密钥最多可以消耗的金额                                 |
| 额度设置 | 无限配额                      | 开启后不单独限制这个密钥的额度，只受账户余额限制           |
| 高级设置 | 模型限制                      | 「选择模型（留空表示允许所有）」，只允许列表中的模型       |
| 高级设置 | IP 白名单（支持 CIDR 表达式） | 每行一个 IP 或网段，留空表示无限制                         |

> [!NOTE]
> 密钥的额度只是这个密钥自己的上限，真正扣费都从账户余额中扣除。余额不足时，即使密钥还有额度，请求也会失败。充值见 [计费说明](/docs/billing)。

### 选择分组

点击「分组」下拉框会显示「选择一个分组」，每个分组旁边有倍率和说明。分组决定三件事：

- 能调用哪些模型，以及支持哪些协议（OpenAI、Anthropic、Gemini 等）。
- 计费倍率：实际费用 = 模型基础价格 × 分组倍率。
- 线路稳定性和价格档位，例如号池分组和稳定分组。

各分组的倍率、说明和可用模型见 [分组说明](/docs/groups)，也可以在 [模型广场](/pricing) 中按分组筛选。

下拉框中还有几个特殊选项：

| 选项     | 含义                                                         |
| -------- | ------------------------------------------------------------ |
| 跟随用户 | 使用账户自身的默认分组                                       |
| 自动     | 「自动选择可用分组，失败时触发熔断切换」，按顺序尝试多个分组 |

选择「自动」后会出现「自动分组顺序」，可以选择并排列这个密钥依次尝试的分组。不调整时显示「继承全局 Auto 顺序」，点击「恢复全局 Auto」可以回到默认顺序。开启「跨分组重试」后，一个分组失败时会继续尝试下一个分组。

> [!IMPORTANT]
> 不同分组的倍率差别很大，同一个模型在不同分组的价格也不同。创建前请先在 [模型广场](/pricing) 确认目标模型所在分组和价格。

## 管理 API 密钥

列表中每一行显示「名称」「状态」「API 密钥」「分组」「额度」「过期」等信息。「额度」列会显示已用和剩余金额，开启无限配额时显示「无限制」。

点击「API 密钥」列中的复制按钮（「复制 API 密钥」）即可复制完整密钥。点击行末的「打开菜单」可以看到以下操作：

| 操作         | 作用                                                             |
| ------------ | ---------------------------------------------------------------- |
| 编辑         | 修改名称、分组、额度、过期时间和高级设置，完成后点击「保存更改」 |
| 复制密钥     | 复制完整的 `sk-` 密钥                                            |
| 复制连接信息 | 复制包含密钥和站点地址的连接信息                                 |
| CC Switch    | 一键把密钥导入 CC Switch，见下文                                 |
| 聊天         | 管理员配置了聊天客户端时出现，可直接把密钥带入对应客户端         |
| 禁用 / 启用  | 临时停用或恢复这个密钥，不会删除                                 |
| 删除         | 永久删除密钥，操作无法撤销                                       |

勾选多行后，可以批量「复制选定的密钥」或「删除选定的 API 密钥」。顶部的「按名称筛选...」「按 API 密钥筛选...」用于在密钥较多时快速查找。

> [!WARNING]
> API 密钥等同于账户的消费凭证。不要把它提交到公开仓库、截图分享或写进前端代码。怀疑泄露时，请立即禁用或删除旧密钥并新建一个。

## 导入 CC Switch

CC Switch 是一个管理 Claude Code、Codex、Gemini CLI 配置的桌面工具。安装好 CC Switch 后：

1. 在密钥所在行打开菜单，点击「CC Switch」。
2. 在「应用」中选择 Claude、Codex 或 Gemini。
3. 按需修改「名称」，在「选择或输入模型名称」中选择主模型。
4. 点击「填入 CC Switch」，浏览器会唤起 CC Switch 完成导入。

导入时站点地址会自动填好：Codex 使用 `{{BASE_URL}}/v1`，Claude 和 Gemini 使用 `{{BASE_URL}}`。完整流程见 [CC Switch](/docs/cc-switch)。

## 测试密钥

创建完成后，可以用模型列表接口确认密钥有效。把 `sk-xxxxxxxx` 换成你的密钥：

<!-- code-group -->

```bash
curl {{BASE_URL}}/v1/models \
  -H "Authorization: Bearer sk-xxxxxxxx"
```

```powershell
curl.exe {{BASE_URL}}/v1/models `
  -H "Authorization: Bearer sk-xxxxxxxx"
```

<!-- /code-group -->

返回 JSON 格式的模型列表即表示密钥可用，列表内容取决于密钥的分组和「模型限制」。返回 401 时请检查密钥是否复制完整、是否已被禁用或过期。发起真正的对话请求见 [发起第一个请求](/docs/first-request)。

### 认证方式

同一个密钥可以用不同客户端习惯的方式传递：

| 方式      | 写法                                                | 常见场景                               |
| --------- | --------------------------------------------------- | -------------------------------------- |
| Bearer    | `Authorization: Bearer sk-xxxxxxxx`                 | OpenAI 兼容客户端，所有接口通用        |
| x-api-key | `x-api-key: sk-xxxxxxxx`                            | Anthropic 风格客户端，例如 Claude Code |
| Gemini    | `x-goog-api-key: sk-xxxxxxxx` 或 `?key=sk-xxxxxxxx` | Gemini 原生接口和 Gemini CLI           |

每个响应都会带上 `X-Oneapi-Request-Id` 响应头。遇到问题反馈时，请附上这个请求 ID，便于排查。更多错误说明见 [错误码](/docs/errors)。

## 常见问题

### 提示额度不足

先在 [钱包](/wallet) 查看「当前余额」。余额充足时，再检查这个密钥是否设置了额度上限并已用完，可以在「编辑」中调高额度或开启「无限配额」。

### 提示模型不可用

确认模型属于密钥所选的分组，并且没有被「模型限制」排除。可以在 [模型广场](/pricing) 中查看模型所在的分组。

### 想为不同工具分开计费

为每个工具单独创建一个密钥，并设置各自的额度。之后在 [使用日志](/usage-logs) 中按令牌筛选，就能看到每个工具的消耗。
