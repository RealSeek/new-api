## 新对话

### 发起对话

点击侧边栏「新对话」进入 `/chat`，在输入框中输入问题，按 Enter 发送，Shift+Enter 换行。

- 模型：点击输入框中的模型按钮打开「选择模型」，可以按「能力」和「厂商」筛选，也可以搜索模型名称、厂商或模型 ID。
- 能力：「能力」一栏可以切换「对话」「图片」「视频」「Agent」。选择「图片」或「视频」时在对话中直接生成，需要接入对应用途的分组；选择「Agent」时只列出支持 Agent 任务的对话模型。
- 助手与技能：登录后可以为对话选择助手和技能，默认是「默认助手」和「不使用技能」，可选项来自「能力中心」。
- 附件：点击输入框中的「+」，选择「添加照片和文件」上传照片或文件。
- 提示词：同一菜单中的「提示词库」用来浏览提示词，「提示词模板」用来使用后台预设的模板。
- 语音：点击麦克风按钮可以语音输入。
- 生成过程中，发送按钮会变为「停止生成」。

> [!TIP]
> 模型选择器显示「暂无配置密钥」时，点击「点击进行配置」，接入一个对话分组即可。编程和推理可以选择 `codex-*` 分组，日常问答可以选择倍率较低的国产模型分组。工作台以 OpenAI 兼容格式调用对话模型，只支持 anthropic 端点的 `claude-*` 分组不保证可用，见 [AI 工作台](/docs/workbench)。

### 管理消息和会话

- 每条回复下方可以「复制」「重新生成」，或标记「有帮助」「没有帮助」。自己发出的消息可以「编辑消息」后重新提交，有多个版本时可以切换「上一个分支」和「下一个分支」。
- 侧边栏「对话」列表按日期排列，点击搜索图标可以「搜索对话」。每条对话的菜单中有「分享」「重命名」「置顶聊天」「归档」「删除」。
- 不想保留记录时，可以点击对话页顶部的「临时聊天」按钮，或在「设置」→「数据控制」中开启「默认使用临时聊天」、关闭「保存聊天记录」。

## AI 创作

点击侧边栏「AI 创作」进入图片创作页 `/image`。在「创作类型」中切换「图片」或「视频」，视频创作的地址是 `/video`。生成结果显示在页面下方，同时保存到「工作空间」的文件库。

### 图片

1. 在「创作描述」中写下想要的画面。
2. 需要参考图时，点击「添加参考素材」上传图片。描述中可以用 `@参考图1` 这样的标记指代对应的图片。
3. 设置参数：「模型」，「比例」（自动、9:16、2:3、3:4、1:1、4:3、3:2、16:9），「风格」（如人像摄影、中国风、动漫、3D渲染等），「图片分辨率」。点击「更多」还可以设置张数等选项。
4. 点击「开始生成」。

模型支持局部编辑时，会出现「区域编辑」和「上传蒙版」：用来圈选需要重绘的区域，或上传已有的蒙版图片。页面上的「灵感中心」提供示例，点击「使用此灵感」会把提示词和推荐参数一起填入。打开生成结果后，可以「用作参考」继续创作、「引用提示词」，或「保存到本机」。

> [!TIP]
> 生图需要接入 `生图` 分组，该分组支持 GPT、Gemini、Grok 生图模型，通常按次计费。图片接口的说明见 [图片生成](/docs/images)。

### 视频

1. 切换到「视频」，在描述中写清楚画面、动作和镜头。
2. 需要参考素材时，点击「引用参考内容」，选择已有素材或「上传参考素材」。所选模型支持时，还会出现「添加参考视频」「添加参考音频」。
3. 选择「模型」「比例」「画质」和时长。时长可以选预设秒数或「自定义」，部分模型支持「自动」，超出支持范围时会自动调整。
4. 点击「开始生成」。视频需要排队处理，卡片上会显示「正在生成视频」和进度，可以点击「停止生成」。

> [!NOTE]
> 视频需要接入 `满血视频` 或 `特价视频` 分组。满血模型能力对齐官方，支持参考图、参考视频和音频；特价模型能力较少，价格更低。参考素材的数量、可用分辨率和时长由所选模型决定，详见 [视频生成](/docs/videos)。

### 任务中心

页面顶部的「任务中心」列出最近的生成任务，状态包括「排队中」「处理中」「已完成」「失败」「已取消」。进行中的任务可以停止，失败或已取消的任务可以重试。「办公中心」页面不显示任务中心，办公任务请在该页的「任务记录」中查看。

## 画布

「画布」用节点把提示词、素材、生成结果组织成可反复修改的创作流程。

### 新建画布

1. 进入 `/canvases`，点击「新建画布」，填写名称。
2. 在「画布类型」中选择「自由画布」（自由组合提示词、图片、视频和生成节点）或「短剧创作」（按剧本、资产、分镜和成片组织镜头）。
3. 「所属项目」可以选择「个人工作区」或某个项目，点击「创建」。

画布列表中可以「创建副本」「归档」「删除」，也可以「导入」JSON 格式的画布文件。

### 使用节点

- 画布工具栏可以添加文本、图片、视频、音频节点和「生成配置」，也可以「上传素材」。在空白处双击可以快速创建节点。
- 在图片或视频节点中写提示词、选择模型后，点击「生成」。连接到它的文本节点会作为提示词一起使用。
- 选中节点后，「节点设置」面板中可以调整尺寸、质量、数量、时长、比例等参数，然后点击「开始生成」。图片节点还支持「裁剪」和「区域编辑」。
- 「套用创作预设」可以一键建立「创意到视频」「图片多方向」「镜头分镜」等节点链路。
- 点击顶部的「Agent」按钮，用文字描述想要的改动，由对话模型规划并操作画布。

### 短剧创作

短剧画布在列表中显示为「短剧工作流」。画布顶部按「剧本」「角色与场景」「分镜」「成片」四个阶段组织内容，提供「制作台」「添加集」「拆分剧本」「添加镜头」等操作。

> [!TIP]
> 点击右上角的快捷键图标可以查看全部快捷键，例如 Ctrl / Cmd + Z 撤销、Ctrl / Cmd + D 复制选中节点。画布同时用到生图、视频和对话，建议三类分组都接入。

## 图片反推

「图片反推」把一张图片分析成可复用的提示词，地址为 `/image-prompt`。

1. 在「参考图片」中拖入或选择一张图片（支持 JPG、PNG、WebP、GIF、AVIF，最大 20 MB），也可以从「文件库」选择，或用 Ctrl+V 粘贴。
2. 选择「提取方式」：「通用」「简洁」「结构化」「平面设计」「JSON」「Flux」「Midjourney」「Stable Diffusion」。
3. 选择「输出语言」：「简体中文」「English」「日本語」。点击「选择对话模型」，选一个能识别图片的模型。
4. 点击「开始反推」。结果分为「正向提示词」「负向提示词」，以及主体、环境、视觉风格、光影、构图等字段。

结果可以「复制」，也可以点击「继续对话」带到对话中，或点击「用于图片生成」填入图片创作的描述框。历史记录在「反推历史」中。

> [!NOTE]
> 图片反推只使用你接入的对话分组中的模型。提示「没有可用的对话模型，请先接入对话 API 密钥」时，请先在「API 与模型」接入对话分组。

## 电商中心

「电商中心」（`/commerce`）根据商品参考图和描述，生成整套营销素材。

1. 点击「添加参考素材」上传商品图，在描述中写明商品、卖点和需要的风格。
2. 在「类型」中选择「详情页」或「素材包」：详情页是按顺序阅读的连续页面，素材包是围绕同一商品的一组独立用途图片。
3. 设置「平台」：自动、淘宝/天猫、京东、拼多多、抖音电商、小红书、Amazon、TikTok Shop、Shopee。
4. 设置模块数量（6、8、10 或 12 个模块），点击「更多」还可以设置格式和背景，然后点击「开始生成」。

> [!TIP]
> 电商中心使用生图模型，需要接入 `生图` 分组。一次会生成多张图片，费用约等于单张价格乘以图片数量，生成前建议先在 [模型广场](/pricing) 确认单价。

## 办公中心

「办公中心」（`/office`）面向写作、表格、演示文稿等需要交付文件的工作，页面标题为「今天要处理什么工作？」。

1. 从「为你推荐」中选择一项能力，例如「PPT 生成」「AI 表格」「帮我写作」「会议纪要」，或点击「更多」打开「办公技能」。
2. 在输入框中描述需要交付的结果，可以点击「添加文件」上传资料，并通过模型按钮选择「选择办公模型」。
3. 在交付文件格式中选择「自动格式」「Word」「Excel」「PowerPoint」或「Markdown」，然后发送。
4. 完成后可以「复制」回答，或点击「生成交付文件」。交付文件会保存到文件库，可以直接下载。

以 Agent 方式执行的任务会显示执行步骤（如「制定计划」「调用工具」「校验结果」）。调用需要审批的工具时会出现「需要你的确认」，点击「允许」或「拒绝」。顶部的「任务记录」可以查看、重新执行或归档历史任务；Agent 任务中还会显示「定时任务」，可以按每天、工作日、每周等计划自动执行。关闭页面后，任务仍会继续执行。

> [!NOTE]
> 办公中心使用对话模型。Agent 任务只能选择支持长上下文的对话模型；提示「当前没有可用的 Agent 模型，请先配置 {{SITE_NAME}} API 密钥」时，请先接入对话分组。

## 提示词库

「提示词库」（`/prompts`）收录了图片和视频提示词，浏览时不调用模型，也不产生费用。

- 顶部切换「图片」或「视频」，可以搜索标题和标签，也可以按「分类」和「热门标签」筛选。
- 每张卡片都可以「复制」，或点击「使用」：页面会跳转到图片或视频创作，并把提示词填入描述框，不会自动开始生成。
- 打开详情可以查看完整提示词，然后选择「复制提示词」或「用于图片生成」「用于视频生成」。

> [!TIP]
> 套用提示词后，生成时仍会按所选模型计费。对话输入框「+」菜单中的「提示词库」也可以进入这里。

## 能力中心

「能力中心」（`/capabilities`）集中管理助手、技能和知识库，需要登录后使用，分为三个页签。

| 页签   | 用途                                           | 操作                                             |
| ------ | ---------------------------------------------- | ------------------------------------------------ |
| 助手   | 平台配置的专业 AI 助手，每个都有默认模型和工具 | 点击「查看」了解详情，再点击「开始对话」         |
| 技能   | 官方技能和你创建的私有技能                     | 「安装到技能库」，或「创建技能」「导入 Skill」   |
| 知识库 | 供助手和 Agent 任务检索的资料                  | 「新建知识库」，在知识库设置中绑定文件库里的资料 |

知识库目前支持文本和 JSON 文件，资料需要先上传到「工作空间」的文件库。创建后的知识库可以绑定到助手和 Agent 任务。私有技能只有你自己可见，不能分享或提交到市场。

> [!NOTE]
> 助手、技能和知识库都在对话或办公任务中使用，费用按你接入的对话分组计算。

## 工作空间

「工作空间」（`/workspace`）包含「项目」和「文件」两个页签，本身不调用模型。

### 项目

点击「创建项目」，填写「项目名称」。项目用来集中保存相关的对话、文件和默认指令。切换到某个项目后，后续的对话、上传和生成内容会归入该项目。在项目详情中可以设置成员、项目技能、默认指令和工作流步骤；分配给团队的项目，团队成员也可以访问。

### 文件库

「文件库」用来管理生成作品、参考素材和办公文件。点击「上传文件」可以上传图片、视频、文档和表格，上传后的文件可以在对话、创作和办公任务中使用。图片、视频、办公交付文件生成后都会自动进入这里，可以搜索、筛选和下载。

> [!TIP]
> 生成的图片和视频在服务器上只临时保留，文件上的「保留至」显示到期时间。「设置」→「数据控制」中的「生成结果自动存到本机」默认开启，会在当前浏览器保存一份副本。需要长期保留的文件请及时下载，更换浏览器或清理浏览器数据前尤其要注意。

## 常见问题

### 选择模型时提示暂无可用模型

对应用途还没有接入分组。打开「设置」→「API 与模型」，在「对话」「生图」或「视频」卡片中选择分组，点击「一键创建并导入」，步骤见 [AI 工作台](/docs/workbench)。

### 生成失败或长时间排队

先在「任务中心」查看任务状态和失败原因，可以重试失败的任务。如果多次失败，可以到 {{SITE_NAME}} 的 [使用日志](/usage-logs) 找到对应请求，记下请求 ID 后在「帮助与客服」中提交工单。常见错误的含义见 [错误码](/docs/errors)。
