{{SITE_NAME}} 采用预付费模式：先在钱包充值，调用模型时从账户余额中扣费。本页介绍价格怎么算、去哪里查看价格、如何充值，以及如何核对每一笔消耗。

## 计费方式

所有价格以 USD 显示。每次请求的实际费用由模型价格和分组倍率共同决定：

```text
实际费用 = 模型基础价格 × 分组倍率
```

模型基础价格分为两类：

| 计费类型 | 计算方式                                                                    | 常见模型                     |
| -------- | --------------------------------------------------------------------------- | ---------------------------- |
| 按量计费 | 按输入、输出 token 数量计费，价格按每 1M token 显示，缓存读写等可能单独计价 | 对话、编程类模型             |
| 按次计费 | 每次请求固定价格，与 token 数量无关                                         | 生图模型、「酒馆」分组的模型 |

视频模型按输出秒数或按任务计费，详见 [视频生成](/docs/videos)。

> [!NOTE]
> 例如某模型输入价格为 $1 / 1M token，在倍率 0.3 的分组中，实际输入价格就是 $0.3 / 1M token。倍率随分组变化，同一模型在不同分组的价格可能相差数倍，分组倍率见 [分组说明](/docs/groups)。

## 查看价格

价格以 [模型广场](/pricing) 为准，本文档中的示例不代表实际价格。

1. 在左侧菜单点击「模型广场」，进入 [模型广场](/pricing)。
2. 用分组、供应商、端点和计费类型筛选，找到目标模型。
3. 点击模型打开详情，查看「定价」中的「输入」「输出」「缓存」等价格，以及「按分组定价」中各分组的实际价格。

价格单位会在页面上标明，例如「价格按每 1M Token 显示」或「每次请求」。部分模型带有「动态计费」或「分档价格表」，价格会随请求条件变化，以详情页显示为准。模型广场的完整用法见 [模型与价格](/docs/models)。

> [!TIP]
> 选好模型后，记下它所在的分组，创建 API 密钥时选择同一个分组，见 [创建 API 密钥](/docs/api-keys)。

## 充值

在左侧菜单点击「钱包」，进入 [钱包](/wallet) 页面。顶部的统计卡片显示「当前余额」（剩余配额）、「总用量」（总消耗额度）和「API 请求」（总请求数）。

### 在线充值

1. 在「添加资金」卡片中选择一个预设金额，或在「自定义金额」中输入金额。低于最低充值金额时页面会提示「最低充值金额：…」。
2. 选择支付方式。可用的支付方式由站点配置，以页面显示为准。
3. 核对「待支付金额：」，点击「支付 …」按钮，按提示跳转到支付页面完成付款。
4. 付款完成后回到钱包页面，确认「当前余额」已经增加。

预设金额旁显示「优惠 …%」时，表示该档位有折扣，实际支付金额以确认页的「您支付」为准。页面提示「没有可用的支付方式。请联系管理员。」时，说明站点暂未开放在线支付，可以改用兑换码。

### 使用兑换码

1. 在钱包页面找到「有兑换码吗？」区域。
2. 在「输入您的兑换码」中填写兑换码，可以一次输入多个，每行一个，不能重复。
3. 点击「兑换额度」。提示「兑换成功！已添加：…」后，额度会立即计入余额。

页面显示「需要兑换码？」和「点此获取」链接时，可以通过该链接购买兑换码。

### 订阅套餐

如果站点开启了订阅功能，钱包页面会显示「订阅套餐」和「我的订阅」。套餐包含一定额度和「有效期」，部分套餐会定期「额度重置」。订阅后可以选择扣费顺序：「优先订阅」「优先钱包」「仅用订阅」或「仅用钱包」。

> [!NOTE]
> 余额和套餐额度只能用于调用模型，不支持提现。充值前请先在 [模型广场](/pricing) 确认要使用的模型和价格。

## 查看消耗

### 计费历史

钱包页面的「计费历史」记录每一笔充值订单，可以用「按订单号搜索...」查找，查看「金额」「付款方式」和订单状态。

### 使用日志

在左侧菜单点击「使用日志」，进入 [使用日志](/usage-logs) 页面。页面分为三个标签：

| 标签     | 内容                                                     |
| -------- | -------------------------------------------------------- |
| 通用日志 | 对话、编程等普通请求的扣费记录，以及充值、退款等额度变动 |
| 任务日志 | 视频等异步任务的提交时间、进度、结果和「失败原因」       |
| 绘图日志 | 绘图类任务的记录                                         |

「通用日志」中每条记录显示「时间」「令牌」「分组」「模型」「Token」「费用」「耗时」等信息，点击「详情」可以看到本次请求使用的价格、「分组倍率」和计算过程。顶部统计显示筛选范围内的「用量」、RPM 和 TPM。

常用筛选条件：

- 「令牌名称」：只看某个 API 密钥的消耗，适合给不同工具分开对账。
- 「模型名称」：只看某个模型的消耗。
- 「请求 ID」：用响应头 `X-Oneapi-Request-Id` 的值定位某一次请求。
- 日志类型：「充值」「消耗」「管理」「系统」「错误」「退款」。

调整条件后点击「搜索」刷新结果。

## 退款说明

视频等异步任务提交时会先预扣费用。任务最终失败时，系统会自动退还预扣的费用，退款记录在「通用日志」中带有「异步任务退款」标记，类型为「退款」。失败原因可以在「任务日志」中查看。

普通同步请求出错时一般不会扣费。如果发现扣费异常，请记下对应的请求 ID，联系管理员处理。

## 推荐计划

如果站点开启了推荐功能，钱包页面会显示「推荐计划」卡片：

1. 点击「复制推荐链接」，把链接分享给朋友。对方通过链接注册后会计入「邀请」。
2. 推荐奖励累计在「可用奖励」中，「总收入」显示累计获得的奖励。
3. 点击「转移到余额」，在「转移金额」中输入金额（不低于「最低：」显示的金额），确认后奖励会转入账户余额。

## 常见问题

### 余额还有，请求却提示额度不足

检查所用 API 密钥是否设置了额度上限并已用完。可以在 [API 密钥](/keys) 页面「编辑」该密钥，调高额度或开启「无限配额」，见 [创建 API 密钥](/docs/api-keys)。

### 为什么同一个模型扣费不一样

不同分组的倍率不同，同一模型在不同分组的价格也不同。另外，缓存命中、输出长度和动态计费条件都会影响单次费用。在使用日志中点击「详情」可以看到每次请求的计算过程。

### 充值后余额没有变化

先刷新钱包页面，再到「计费历史」中查看订单状态。订单已付款但余额未到账时，请带上订单号联系管理员。
